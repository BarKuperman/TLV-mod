# Tel Aviv Map Mod

This mod adds the city of Tel Aviv to the game. 

> **Note:** This mod is currently available for **Windows only**. It is very much a Work in Progress, and the demand data is currently not good at all.

> **Note:** You can try the **mac branch** in this rep for mac and linux support but no promises.

## Installation

Follow these steps to install the mod:

1. **Download and extract** the mod files to your computer.
2. Place the extracted folder into your game's `mods` directory.
3. Launch the game and navigate to the **Mod Manager**.
4. Enable the Tel Aviv mod.
5. Click the **Reload Mods** button.
6. Close the Game

## How to Play

Because this mod relies on an external script, you will need to follow these steps every time you play:

1. Go to your local mod folder and run the `run_windows` executable file. 
2. A terminal window will open. **Do not close this terminal** while you are playing.
3. Enter the game and press `Ctrl + Shift + R` to initialize the mod. *(You must do this every time you launch the game).*
